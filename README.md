# Protection Engineering · 工程防护

![展示](doc/展示.png)
Minecraft NeoForge 1.21.1 模组。为工程师护甲系统提供**可安装附件**，每个附件安装在护甲的特定槽位上，提供被动免疫、属性加成或主动技能。依赖 **Create** 模组。

策划/美术：Rhodes_Koei  
代码：Chemiofitor

## 护甲

4 件工程师护甲，下界合金级属性（护甲 3/8/6/3，韧性 3.0，击退抗性 0.1），耐久为下界合金的 1.5 倍，不可附魔：

| 护甲 | 专属槽位 |
|------|----------|
| 工程师兜帽 | 眼部、嘴部 |
| 工程师胸甲 | 肩部、胸甲板、背部、手臂 |
| 工程师护腿 | 腿部、膝部 |
| 工程师劳保靴 | 脚部 |

> 每件护甲另有通用槽位：`LINING`（内衬）与各自装饰槽（`HELMET/CHESTPLATE/LEGGINGS/BOOTS_DECORATION`）。全套装共 **17 个附件槽位**（9 专属 + 4 内衬 + 4 装饰）。胸甲安装喷气背包/动量背包后可鞘翅滑翔；靴子安装改良鞋底后可细雪行走。

## 方块

| 方块 | 功能 |
|------|------|
| 盔甲改装台 | 安装/拆卸护甲上的附件（护甲槽 1 + 附件槽 4，槽位多时翻页） |
| 护甲发射器 | 与 Create 机械臂联动：站在上面的生物被自动穿戴护甲/安装附件；Shift+右键切换脱装备/拆附件/全部移除模式 |

## 配置

### 客户端 (`protectionengineering-client.toml`)

```toml
[HUD]
hudOffsetX = 4   # HUD 距屏幕右边（像素）
hudOffsetY = 4   # HUD 距屏幕顶部（像素）
```

### 服务端 (`protectionengineering-server.toml`)

```toml
[aps]
interceptRange = 5.0       # 拦截半径（格）
activeDuration = 200       # 激活窗口（tick）
cooldownTicks = 600        # 冷却（tick）

[missile]
targetRange = 512.0        # 锁定射程（格）
flightSpeed = 3.0          # 巡航速度（block/tick）
closeSpeed = 4.5           # 末端冲刺速度
maxLife = 200              # 最大寿命（tick）

[rocket]
cooldownTicks = 200

[hormone]
cooldownTicks = 1200

[dodge]
dodgeStrength = 1.0        # 弹射力度
cooldownTicks = 200

[repair]
brassSheetUnits = 3        # 黄铜板修补强度（20 = 修满耐久）
sturdySheetUnits = 10      # 坚固板修补强度
```

## 兼容

- **必需**：Create（配方材料 / 眼镜系统 / 潜水靴 / 机械臂交互）
- **可选**：Detail Armor Bar Reconstructed（自定义护甲条）、Iron's Spells 'n Spellbooks（9 个学派内衬）、PlayerAnimator（弯曲动画兼容）、JEI（配方查看）

## 开发

```bash
./gradlew runClient    # 启动客户端
./gradlew runData      # 生成数据文件（语言、配方）
./gradlew build        # 构建 JAR
```
